img2homog

Black-and-white unit-cell image → N×N 0/1 bitmap for FE asymptotic homogenization (Guedes & Kikuchi, 1990), with validation checks. Runs the repository's own Python in your browser — the image never leaves your computer. Source & documentation.

Drop a PNG/JPG of one periodic unit cell here, or click to choose.
Image borders = cell boundaries. Prefer PNG.

Options
What do these options mean?
N
Output grid size: the bitmap is N×N pixels (= finite elements in the homogenization). Use 100/200 for convergence studies; make sure the thinnest wall keeps ≥ 4 px (the report warns you if not).
solid
Which tone is material. dark = black cell on white background (the usual case); light = inverted images (white cells on dark background, e.g. micrographs).
threshold
Grey level (0–1) separating solid from void. Irrelevant for clean black/white images; for anti-aliased or scanned images, lower it (e.g. 0.3) to accept only dark greys (thinner walls) or raise it to thicken them. The report warns when many grey pixels are present.
rule
How each output pixel is decided when the source image has more resolution than N. area: solid if ≥ min-frac of the pixel's area is material (more faithful solid fraction — recommended). center: copies the source pixel at the centre point.
min-frac
The area-rule cutoff (default 0.5). Lower it (e.g. 0.3) to rescue a very thin wall that is vanishing in the resampling; raise it for the opposite. Change it only in response to a report warning.
reference fraction
Optional check: the theoretical solid fraction of the cell, if known. The report then shows the deviation and warns above 0.02. It never changes the result. Example cells: re-entrant 0.398, missing-rib 0.345, chiral 0.289, rotating 0.397.
